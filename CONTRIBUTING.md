# Contributing

Issues and pull requests that improve the proofs, verification, documentation,
or reproducibility are welcome.

Before opening a pull request:

1. run `./verify_all.sh`;
2. keep all certificate arithmetic exact;
3. add or update a mutation test when changing verifier acceptance logic; and
4. explain any change to the mathematical statement or construction.

Please report suspected mathematical errors with a minimal counterexample or a
precise reference to the affected theorem, lemma, or verification condition.
